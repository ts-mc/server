# `.docs/` — things that are **not** transferred to the Minecraft server

DO NOT EDIT ANY .JAR FILE

This folder is the "everything that is not server runtime" pile. Anything in the
repository **root** is meant to be uploaded to the Minecraft host; anything in
here is repository-side material only.

| Folder | What it is | Why it stays here |
|--------|------------|-------------------|
| `docs/` | Project documentation, guides, Discord announcement drafts | Reference material; the server never reads it |
| `dot-apollo/` | Apollo panel crash reports | Panel-side logs, not server state |
| `dot-trash/` | Old zeroed log files kept during the corruption cleanup | Dead weight |
| `dot-kilo/` | Agent/tool worktree artifacts | Local tooling |
| `dot-cache/` | Local JVM `JNA` cache | Regenerated by Java on the host; never upload |

## `updates/` (repository root)

The [`../updates/`](../updates/README.md) folder (repository root, **is**
transferred conceptually as documentation) holds the changelog: one dated file
per work session describing exactly what was changed and why. Newest first,
indexed in its README.

> The folders keep their original names with `dot-` prefixes where they were
> hidden directories (`.vscode`, `.kilo`, `.apollo`, `.trash`, `.cache`).
