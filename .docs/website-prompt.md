## What we are

TheySix Events is a **minigame Minecraft server** featuring 19 unique minigames across 6 dedicated arena worlds. Games range from 1v1 duels to 10v10 team chaos, with parkour, combat, party, and elimination games. Players vote for the next game each round and compete on arena leaderboards.

## How to join

1. Add `play.theysix.tech` (Java) or `bedrock.theysix.tech:25832` (Bedrock) to your Minecraft server list
2. Join the server (Java Edition 1.21.11+)
3. On join, follow the lobby instructions
4. Use `/ba quickjoin` or the lobby GUI to join a random arena
5. Use `/ba join PG-01` (or any arena ID) to join a specific arena
6. Vote for the next game when prompted
