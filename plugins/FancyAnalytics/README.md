# FancyAnalytics — Analytics Guide

FancyAnalytics is the telemetry/analytics library used by the Fancy plugins on
**TheySix Events** (`play.theysix.tech`).

## Files

| File | Purpose |
|------|---------|
| `config.json` | FancyAnalytics settings |

## Notes

- It supports the Fancy plugins (FancyNpcs, FancyHolograms, FancyGlow) with
  anonymous usage data.
- Disable it in its config if your policy forbids third-party telemetry.
- No player-facing commands or branding apply.
